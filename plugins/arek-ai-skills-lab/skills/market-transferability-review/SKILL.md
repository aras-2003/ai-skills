# Market Transferability Review

## Purpose
Test whether the reasons a product works in the source market exist in the target market.

## Preconditions
Require explicit source and target markets plus the source-market success thesis. If target-market context cannot be evidenced, keep transferability unresolved.

## Inputs and evidence
Use target-market context, substitutes/price anchors, household/lifestyle/use environment, regulation, distribution/fulfilment and willingness-to-pay evidence. Source-market traction stays source-market evidence.

## Uncertainty and tool failure
If live local evidence cannot be retrieved, do not infer local prevalence, price acceptance or demand from source-market reviews. State the cheapest local evidence needed next.

## Procedure
1. State source-market success hypothesis.
2. Separate universal problem drivers from market-specific drivers.
3. Compare customer behaviour, willingness to pay, household/lifestyle context, climate, regulation, distribution, fulfilment and category maturity.
4. Identify target-market substitutes and local price anchors.
5. Separate transferable product value from non-transferable channel/cultural advantages.
6. Sequence validation from cheapest context evidence to more expensive offer/channel tests.
7. State what must be tested locally before launch.

## Decision rules
- Source-market traction is evidence about the source market, not the target market.
- Similar demographics do not prove similar willingness to pay.
- Universal problem != transferable use context.
- Do not use TAM alone as transfer evidence.
- Validate target-context prevalence, substitutes and basic logistics before copying the source-market offer into a landing/paid test.

## Output contract
Source success driver | target-market match | mismatch | confidence | evidence | local test required.
Then: transferability = strong / plausible / weak / unresolved.
Then: staged local validation path = cheapest context screen -> next evidence gate -> offer/channel test only if earned.

## Quality checks
- [ ] Source and target evidence are separate.
- [ ] Local use context and substitutes are explicit.
- [ ] US/source traction is not local purchase evidence.
- [ ] Evidence steps are staged cheapest-first.
