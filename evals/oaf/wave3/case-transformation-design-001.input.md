# OAF Transformation Design — Workflow Case 001

## Scenario

A multinational technology organisation has selected a federated shared-capability operating-model direction.

Validated diagnosis:
- duplicated local integration/data solutions;
- global platform lead times too long;
- unclear exception decisions;
- local budgets inhibit shared capability funding;
- capacity bottleneck in the global data team.

Selected target direction:
- shared enterprise platforms and standards;
- local configuration and bounded extensions;
- pooled/shared funding for shared capabilities;
- explicit exception rights;
- minimal decision-led governance.

Leadership has approved a 90-day mobilisation phase but not a multi-year program.
