# Global / Local Model Review — Case 001

## Scenario

A multinational technology organisation operates across several countries.

Current signals:
- global teams define architecture standards, cybersecurity controls and core platforms;
- local markets own business relationships, operational priorities and some local applications;
- global standards are frequently perceived as too slow or poorly adapted to local needs;
- local markets have created workarounds and local tools to maintain delivery speed;
- duplicate solutions and integration costs are growing;
- global leadership wants more standardisation;
- local leadership fears loss of responsiveness and accountability;
- no shared rule exists for deciding which capabilities/decisions should be global versus local.

Evidence is incomplete and stakeholder accounts conflict.
