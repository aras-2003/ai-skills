# Commerce Opportunity Framework

## Objective
Turn product ideas into evidence-backed test/kill decisions with minimum wasted research, inventory and ad spend.

Core loop:

```
Signal -> Problem -> Product/Offer -> Demand -> Competition -> Economics -> Supply/Risk -> Acquisition -> Test -> Evidence -> Scale/Adjust/Kill
```

## Architecture

### Opportunity
- product-opportunity-discovery
- market-transferability-review

### Demand
- problem-demand-validation

### Market
- competition-landscape-review

### Product/offer
- differentiation-review

### Economics
- unit-economics-review

### Operations
- supplier-viability-review

### Growth
- acquisition-fit-review

### Risk
- commerce-regulatory-risk-review

### Workflows
- commerce-product-deep-dive
- commerce-opportunity-review

## Gate model

1. Problem
2. Differentiation
3. Economics
4. Acquisition
5. Supply/regulation
6. Optional relative prioritisation

Do not score before fatal gates are checked.

## Evidence model
For material claims separate:
- Evidence
- Hypothesis
- Unknown

## Decision states
- BADAĆ TERAZ
- TESTOWAĆ
- ODŁOŻYĆ
- ODRZUCIĆ

## Stop conditions
Kill early when economics, compliance, logistics or commodity pressure is structurally fatal.
Stop research and run a bounded market test when the remaining uncertainty is empirical conversion/CAC/offer response.
