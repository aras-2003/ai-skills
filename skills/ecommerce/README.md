# Ecommerce

Skills for customer journey, merchandising, conversion and release quality.

| Skill | Purpose |
|---|---|
| `customer-journey-review` | Review the end-to-end customer journey and identify friction. |
| `collection-merchandising` | Evaluate collection structure, product grouping and discovery. |
| `product-page-critique` | Review value proposition, proof, clarity and purchase confidence. |
| `conversion-friction-audit` | Identify likely causes of abandonment or hesitation. |
| `copy-quality-review` | Check clarity, usefulness, tone and unsupported claims. |
| `brand-consistency-review` | Check consistency of visual and verbal brand execution. |
| `mobile-commerce-review` | Review mobile-first usability and purchase flow. |
| `checkout-readiness` | Review checkout experience, trust and missing information. |
| `release-readiness` | Final judgment-heavy release gate after deterministic technical tests pass. |
