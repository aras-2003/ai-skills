# Web / Design / Motion

Skills for turning strategy and content into high-quality web concepts and implementations.

| Skill | Purpose |
|---|---|
| `reference-analysis` | Extract useful mechanics from visual references without copying surface style. |
| `concept-to-metaphor` | Translate business meaning into a clear visual/system metaphor. |
| `motion-storyboard` | Define motion, scroll choreography, state transitions and narrative sequence. |
| `design-critique` | Review hierarchy, clarity, executive feel, originality and visual quality. |
| `implementation-brief` | Convert an approved concept into a precise build specification. |
| `visual-regression-review` | Compare implementation against approved concept and identify regressions. |
| `seo-content-audit` | Review metadata, content structure and discoverability. |
| `accessibility-gate` | Review accessibility risks not already covered by deterministic tests. |

Rule: deterministic tests such as broken links, responsive checks and accessibility scans belong in CI where possible; AI skills handle judgment-heavy review.
