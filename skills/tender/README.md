# Tender / RFP

Skills for structured tender analysis and bid/no-bid decisions.

| Skill | Purpose |
|---|---|
| `rfp-extraction` | Extract requirements, deadlines, evidence and contractual obligations. |
| `eligibility-check` | Identify mandatory conditions and disqualifying gaps. |
| `requirement-classification` | Classify requirements by domain, criticality and response type. |
| `capability-evidence-match` | Map requirements to existing capabilities and evidence. |
| `requirement-traceability` | Maintain requirement-to-response-to-evidence traceability. |
| `evidence-gap` | Identify unsupported claims and missing proof. |
| `delivery-risk-analysis` | Assess delivery, dependency, staffing and timeline risks. |
| `commercial-risk-analysis` | Assess pricing, contractual and commercial exposure. |
| `bid-score` | Produce structured scoring inputs; deterministic code should calculate final weighted score. |
| `go-no-go` | Produce decision rationale using explicit thresholds and evidence. |
| `red-team-bid` | Challenge the response from evaluator and competitor perspectives. |
