# Learning OS

> **Status:** design/backlog documentation only. This domain currently contains no implemented `SKILL.md` files. The items below are proposed capability names, not current source or runtime availability.

Minimal set of reusable learning skills. Avoid over-engineering the learning process.

| Skill | Purpose |
|---|---|
| `knowledge-diagnosis` | Infer the smallest important knowledge/skill gap. |
| `concept-explainer` | Teach the minimum theory needed for the next capability gain. |
| `practice-generator` | Generate realistic application tasks with progressive difficulty. |
| `competence-check` | Assess demonstrated performance rather than exposure or confidence. |
| `retention-review` | Use recall, synthesis or comparison when it materially improves retention. |

Default workflow:
`diagnose -> explain minimum -> apply -> assess -> next`.
