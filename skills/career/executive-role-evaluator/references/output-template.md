# Executive Role Evaluator Output Template

## Default compact format
Use this when the user has not requested another layout:

```
Decision: PURSUE / INVESTIGATE / LOW PRIORITY / SKIP
Confidence: HIGH / MEDIUM / LOW
Role archetype: ...
Role Quality: STRONG / MIXED / WEAK / UNKNOWN
Candidate Fit: STRONG / GOOD / PARTIAL / GAP / UNKNOWN
Career Value: HIGH / MEDIUM / LOW / UNKNOWN
Risk: LOW / MEDIUM / HIGH / VERY HIGH
```

Then provide only the sections that materially support the decision:
- what the role really is;
- strongest reason to pursue;
- strongest reason not to pursue;
- critical unknowns;
- recommended next action.

## User-requested format
If the user asks for a table, memo, comparison, short answer or another format, use it. Do not force the default first block. Preserve the same substantive fields: decision, confidence, material risks, strongest counterargument and critical unknowns.

## Comparison mode
Use the same qualitative method across opportunities. Compare trade-offs without converting labels or UNKNOWNs into a numeric ranking.

## Update mode
Update only dimensions affected by new evidence, preserve prior evidence and show what changed.

## Evidence discipline
Use `UNKNOWN` where evidence is missing. Do not invent /100 totals or unsupported candidate experience.
