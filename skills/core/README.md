# Core skills

Cross-domain procedures reusable across projects.

| Skill | Purpose |
|---|---|
| `research-brief` | Turn a problem into a research scope, questions, evidence requirements and output format. |
| `evidence-validator` | Check source quality, freshness, contradictions and strength of evidence. |
| `structured-comparison` | Compare alternatives using an explicit, consistent criteria matrix. |
| `decision-brief` | Compress analysis into options, trade-offs, risks, unknowns and next decision. |
| `red-team-review` | Stress-test a recommendation and identify the strongest counterargument. |
| `quality-gate` | Verify that an output meets defined acceptance criteria before release. |
| `handoff-generator` | Create a concise handoff for another model, agent or workflow. |
| `change-review` | Compare versions and identify regressions, improvements and unresolved issues. |

These should be implemented first because other domains can reuse them.
