# Product Research / USA -> Poland

Skills for discovering and validating physical product opportunities before capital is committed.

| Skill | Purpose |
|---|---|
| `signal-scout` | Find products, problems and demand signals in source markets. |
| `problem-validation` | Verify that the customer problem is real, painful and sufficiently frequent. |
| `poland-demand-check` | Validate local search demand, buying behavior and market fit. |
| `competition-landscape` | Map direct competitors, substitutes, pricing and saturation. |
| `why-would-they-buy` | Explain why a customer would choose the product over cheaper alternatives. |
| `supplier-feasibility` | Assess sourcing, MOQ, logistics, lead time and supplier risk. |
| `unit-economics` | Calculate gross margin, contribution margin, CAC ceiling and break-even. |
| `regulatory-screen` | Flag regulatory, safety, import and compliance issues. |
| `meta-ad-test-design` | Design a low-cost demand experiment with explicit pass/fail criteria. |
| `investment-decision` | Produce GO / TEST / REJECT decision from validated evidence. |

Suggested gates:
`signal-scout -> problem-validation -> poland-demand-check -> competition-landscape -> why-would-they-buy`

Only then:
`supplier-feasibility -> unit-economics -> regulatory-screen -> meta-ad-test-design`.
