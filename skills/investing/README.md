# Investing domain

Purpose: evidence-disciplined personal investment research and portfolio decision support.

Design rules:
- decision support, not automated trading;
- XTB-investable universe for v1;
- research quality and portfolio fit are separate;
- conviction and position sizing are separate;
- current state never overwrites decision history;
- material claims carry source date, as-of date and evidence status;
- Google Drive is the intended durable user datastore; no personal portfolio data belongs in this repository;
- recommendations must expose uncertainty, downside and what would invalidate the thesis.

Primary workflows:
- investment-opportunity-hunter
- investment-security-review
- investment-portfolio-review
- investment-theme-discovery
